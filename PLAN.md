# safeguard-shoplift — MVP (demo)

**Цель:** проверить модель — распознавание людей (регистрация + идентификация) **и**
идентификация товара, который человек держит. Всё.

**Хостинг:** бесплатный приватный HuggingFace Space, CPU, диск эфемерный.
**Вне scope:** юрисдикция, биометрия-регулирование, «воровство», касса (POS).

---

## Стек (решения)

| Слой | Выбор | Почему |
|---|---|---|
| Python | 3.13 (venv) | единственный на машине; значит TensorFlow/DeepFace отпадает → идём на facenet-pytorch |
| UI | Gradio, `gr.Image(sources=["webcam"], streaming=True)` | отдаёт кадры на сервер, работает на телефоне по HTTPS |
| Детекция объектов | Ultralytics `yolov8n` (pretrained COCO) | классы banana/apple/orange/sandwich/pizza/cake/bottle/cup/bowl уже есть |
| Лица | `facenet-pytorch` (**рекоменд.**) | чистый PyTorch, ставится без TF и без сборки C++; embedding 512-d |
| Лица (альт.) | `insightface` | быстрее, но требует Visual Studio Build Tools на Windows |
| Лица (альт.) | `DeepFace` | тянет TensorFlow → только Python ≤ 3.12 |
| Хранилище | SQLite (эмбеддинги, без фото) | просто, для демо хватит; FAISS не нужен |
| Трекинг | `model.track(..., persist=True)` | track_id для связи товар↔человек |

---

## Этапы

0. **Каркас** — venv, `requirements.txt`, пустой `app.py` с Gradio, локальный запуск.
1. **Детекция + товар** — YOLO, фильтр COCO-классов, трекинг, оверлей боксов.
2. **Люди** — регистрация (имя + кадры → эмбеддинг), идентификация по косинусу, SQLite.
3. **Связка** — человек ↔ товар по пересечению боксов.
4. **Деплой** — приватный HF Space, README-фронтматтер, проверка с телефона, ПК выключен.

---

## Известные грабли

- **HTTPS для камеры** — браузер без secure context камеру не даёт; хостинг решает.
- **Free Space: диск эфемерный** — `people.db` сбросится при рестарте/ребилде (принято).
  Если надоест — обход через приватный HF Dataset или переезд на VPS.
- **SQLite + потоки Gradio** — соединение на вызов (`check_same_thread` + lock).
- **Стейт трекера** — держать на глобальном объекте, изолировать по `session_hash`.
- **Python 3.13 + TensorFlow несовместимы** (открытые issue в tensorflow/tensorflow).

---

## Критерии готовности

- Открывается на телефоне по HTTPS, камера работает.
- Регистрирую человека → он опознаётся.
- В кадре определяется товар из списка COCO.
- В оверлее: бокс человека + имя; бокс товара + класс.
- ПК выключен — демо доступно с телефона.
